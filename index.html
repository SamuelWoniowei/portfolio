case 01· threat intelligence· network forensics

          
An infostealer, traced from five minutes of traffic

          
Given 286 seconds of packets from a compromised Windows workstation, I reconstructed the whole attack: a suspected watering-hole site, a payload download, a Telegram ping to the operator, then a command-and-control server that fingerprinted the machine and shipped the details out. It matched documented Lumma Stealer behaviour.

        

        
WiresharkNetworkMinerCyberChefVirusTotalMITRE ATT&CKOpenCTIVECTR

      


      

        

          
          03:11:12
          real timestamps · select any event · the quiet 2m45s is collapsed
        

        

        
        

      


      

        
What I found
  • The first packet was a DNS lookup for a four-year-old site flagged by 8 vendors, which is what you would expect from a compromised legitimate site.
  • A page titled "test" served JavaScript that harvested GPU, canvas, screen, audio and network details.
  • VM artefacts suggested the malware may have held some behaviour back.

        
What I recommended
  • Isolate the host, rotate its credentials and block the indicators straight away.
  • Sweep the rest of the /24 within 24 hours.
  • Add TLS inspection and EDR; report to the ICO within 72 hours (UK GDPR Art. 33).

        
Where it falls short
  • The 16 MB payload was encrypted, so I couldn't confirm what hit disk.
  • I could say the pattern matches Lumma, not that it is Lumma for certain. That would need a malware sample.
